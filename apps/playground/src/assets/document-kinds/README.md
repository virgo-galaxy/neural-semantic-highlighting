# Document kind icons

CSS, SCSS, Less, HTML and Vue icons come from [Devicon](https://devicon.dev/),
revision `32fe1d3b3f36ad11f90ab94f7db59738139c2bf6` of [devicons/devicon](https://github.com/devicons/devicon).

| Local file | Upstream file                        |
| ---------- | ------------------------------------ |
| `css.svg`  | `icons/css3/css3-original.svg`       |
| `scss.svg` | `icons/sass/sass-original.svg`       |
| `less.svg` | `icons/less/less-plain-wordmark.svg` |
| `html.svg` | `icons/html5/html5-original.svg`     |

The Vue icon is `vue.svg`, from `icons/vuejs/vuejs-original.svg` in the same
revision. The upstream MIT license is preserved in `DEVICON-LICENSE.txt`.

The Python icon is `python.svg`, from `icons/python/python-original.svg` at the
same pinned revision and under the same preserved license.

The Shell icon is `bash.svg`, from `icons/bash/bash-original.svg` at that same
revision and under the preserved Devicon license.

The Perl icon is `perl.svg`, from `icons/perl/perl-original.svg` at that same
pinned revision and under the preserved Devicon license.

The AWK icon is `awk.svg`, from `icons/awk/awk-original.svg` at that same
pinned revision and under the preserved Devicon license.

The SQL icon is `sql.svg`, from `icons/azuresqldatabase/azuresqldatabase-original.svg`
at that same pinned Devicon revision and under the preserved license. It denotes
the SQL entry, whose supported profiles are PostgreSQL, MySQL and Oracle.

The PowerShell icon is `powershell.svg`, from `icons/powershell/powershell-original.svg`
at that same pinned Devicon revision and under the preserved license.

The BAT / CMD icon is `bat.svg`, from `icons/windows11/windows11-original.svg`
at that same pinned Devicon revision and under the preserved license.

The Assembly entry uses `assembly.svg`, from `icons/nasm/nasm-original.svg`
at that same pinned Devicon revision and under the preserved license. The icon
comes from NASM; the entry also covers GNU/AT&T, MASM and AArch64 source.
