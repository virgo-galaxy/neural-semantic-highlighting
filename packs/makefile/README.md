# Makefile pack

One standalone neural model for common GNU Make source: targets/prerequisites,
assignment flavors, automatic/substitution variables, nested built-in functions,
directives/conditionals, opaque define values, recipes, dollar escaping,
continuations and bounded literal recipe prefixes. Browser inference requires no
Make executable, SDK, Python, parser or nested Shell model.

See [semantics](SEMANTICS.md), [dataset](dataset/README.md),
[Golden](fixtures/README.md), [training](../../training/makefile/README.md)
and the root [consumer guide](../../README.md).
