# Independent Diff/Patch Golden

28 hand-marked original-coordinate cases cover unified/Git headers, hunk/body
priority, context, additions/deletions, empty changed lines, whitespace, new and
deleted files, quoted paths, multiple hunks, rename/copy/mode metadata, binary
notices, mail preambles, no-newline markers, fragments, Unicode separators,
CRLF/BOM and UTF-16 offsets. They are never collected as training data.
Teacher agreement, strict neural agreement and natural unseen accuracy remain
separate. Playground examples are separately authored visible development probes.
