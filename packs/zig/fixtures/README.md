constants/locals, struct/enum/error declarations, comptime types, optionals/captures,
current builtins/contextual calls, quoted identifiers, strings/characters/multiline literals,
comments, arrays and original BOM/CRLF/Unicode coordinates.

accuracy. Golden and Playground are never training collection roots.
