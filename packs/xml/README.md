# XML / SVG pack

One shared neural model with distinct `xml` and `svg` entry points. Tags,
attributes, namespace-qualified names, comments, declarations, entities, text
and opaque CDATA retain original source ranges. No Python or XML/SVG SDK is
required by frontend consumers.

See [semantics](SEMANTICS.md), [dataset](dataset/README.md),
[Golden](fixtures/README.md), [training](../../training/xml/README.md)
and [consumer integration](../../README.md).
