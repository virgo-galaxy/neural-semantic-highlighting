# XML / SVG dataset

External data stays under `~/Datasets/neural-semantic-highlighting/xml`.
One pack contains distinct XML and SVG profiles with one shared assignment map.
Pinned public MSBuild/Android XML and VS Code/Devicon SVG captures retain original
Git commit/tree/blob identities, bytes and applicable licenses. Fixed path-hash
selection follows independent Expat/range validation, without consulting Golden,
Playground or model results. Sources, external DTDs and stylesheets never execute.

40 original tree families have 24 XML and 24 SVG variants each (1,920 tasks).
Both kinds from one family always stay in the same fold. Product/module/icon
families group natural captures before exact/lexical/structural copy auditing.
Freeze all retained assignments before training. Golden and 16 display probes
stay outside source collection; do not interpret their scores as unseen accuracy.

`make dataset-xml-tools` fingerprints existing CPython/Expat; no SDK, package or
language runtime is installed. `make dataset-xml` creates immutable corpus/Gold/
prepared snapshots. Resume only full optimizer/RNG checkpoints in artifacts/xml;
never use packs/*/model/model.pt or ONNX. Preserve earlier captures, data revisions,
experiments and formal weights. Review validation before freezing the candidate;
the first adaptive held-out test is final and cannot drive another training run.
