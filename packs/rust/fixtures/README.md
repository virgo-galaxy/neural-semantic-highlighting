# Independent Rust Golden

Twenty-three hand-authored marked cases cover source-local function/parameter,
struct/enum/trait, constant/generic/lifetime, imports/attributes/macros, raw/byte/C
strings, closures/labels, raw identifiers, nested comments, BOM and async/await.
All original UTF-16 coordinates and declaration modifiers are checked independently.
These cases and the Playground examples are never collected for training.
