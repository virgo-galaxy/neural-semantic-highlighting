# Protocol Buffers pack

One standalone model highlights `.proto` source: proto2/proto3 and grammar-supported
editions, messages, enums, services/RPC streams, maps/oneofs, imports, reserved
fields, custom/aggregate options, comments and original string ranges. Inference
needs no protoc, SDK, Python, imported schemas or code-generation service.

See [semantics](SEMANTICS.md), [dataset](dataset/README.md),
[Golden](fixtures/README.md), [training](../../training/protobuf/README.md)
and the root [consumer guide](../../README.md).
