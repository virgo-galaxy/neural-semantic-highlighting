# Independent protobuf Golden

26 hand-marked cases cover original syntax/editions declarations, packages,
imports, message/field/scalar/qualified names, enums, maps, oneofs, RPC streams,
options and aggregate values, reserved ranges, visibility, extensions, nested
messages, concatenated literals with interleaved comments, Unicode, CRLF and BOM.
Golden and the independently authored Playground examples never enter training.
Teacher agreement and neural whole-case accuracy remain distinct evidence.
