# Ruby independent Golden

33 separately hand-marked cases cover declarations, classes/modules, methods,
instance/class/global variables, constants, calls, keyword labels, symbols/hashes,
blocks/numbered parameters, lambdas, patterns, plain/percent/regex strings,
interpolation, quoted/indented heredocs, explicit line continuation, CRLF/Unicode and `defined?`.
Expectations are independent of teacher output and excluded from training.
Teacher and neural Golden agreement are distinct from natural held-out evidence.
