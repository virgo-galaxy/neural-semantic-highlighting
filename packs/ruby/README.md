# Ruby pack

Common modern Ruby source and build/DSL files: classes/modules, methods, blocks,
keyword arguments, patterns, symbols, hashes, safe navigation, heredocs,
percent/regex literals and interpolation. Rails/Rake/Rack/RSpec syntax shares one
model without executing dependencies or claiming framework API validation.

See [semantics](SEMANTICS.md), [dataset](dataset/README.md), [Golden](fixtures/README.md)
and [training](../../training/ruby/README.md). Offline Gold uses fixed
[tree-sitter-ruby](https://github.com/tree-sitter/tree-sitter-ruby) and original
source ranges. No Ruby SDK, gem environment or global dependency is installed.
