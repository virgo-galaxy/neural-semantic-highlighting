# Ruby dataset

`make dataset-ruby` retains original source and root/component licenses under
~/Datasets/neural-semantic-highlighting/ruby. Four bounded Git-pinned captures use
Rails Active Support, Rake, Rack and RSpec Core. Original bytes, blob hashes and
licenses are preserved. The original curriculum adds 56 separate families with
24 variants each, including plain/quoted/indented/multiple/call heredocs, blocks,
patterns, ordinary and Rails-style Ruby, regex and percent strings.

Golden, tests and Playground never enter collection roots. Raw corpus, Gold and
prepared snapshots remain immutable, with copy audits before windows and frozen
source families before training. Natural and authored focus evidence remain
separate. Full optimizer/RNG experiments stay under artifacts/ruby; inference
.pt/ONNX bundles never contain resumable training state.

Offline parser/runtime sources compile with existing Clang only in ignored
project cache. No Ruby SDK, interpreter, gem or global dependency is installed.
Collected source, build files, subprocesses, projects and dependencies never run.
Parser, original-byte/Unicode and coverage errors fail closed with explicit
quarantines. A permissive EOF heredoc is rejected unless its CST end is nonempty.

A separate mixed generator adds 12 independent families / 288 variants after
visible review of qualified names, instance calls, heredocs and mixed literals.
The initial 56 families and every frozen assignment remain preserved.
