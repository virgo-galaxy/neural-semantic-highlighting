# .env pack

Common dotenv configuration highlighting: variable declarations, optional export,
plain/quoted/multiline strings, hash comments, empty values and opaque references.
Frontend consumers need no Python, dotenv loader or language SDK.
See [semantics](SEMANTICS.md), [dataset](dataset/README.md),
[Golden](fixtures/README.md), [training](../../training/dotenv/README.md)
and [consumer integration](../../README.md).
