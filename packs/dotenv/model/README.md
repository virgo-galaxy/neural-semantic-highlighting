# .env neural model

Common .env/.env.* dotenv configuration, variable declarations, export, plain/single/double/backtick and multiline string values, hash comments, empty values and opaque references.

```ts
const { html } = await highlighter.highlight(source, { language: "dotenv" });
```

dotenv, env and .env (case normalized) share one descriptor and canonical dotenv output. Filename examples include .env, .env.local and .env.production; the API takes an explicit language rather than auto-detecting file content.
Selective import: `@nsh/highlighter/languages/dotenv`. Case-normalized IDs share one
model. Browser/Playground consumers require no language SDK, interpreter/compiler,
parser, dependency environment or Python process. Offline Gold uses Pinned official dotenv 18.0.10 parse-only npm assets with retained BSD-2-Clause license and archive/per-file hashes, using existing Node only.
Collected configurations are never executed or built.
