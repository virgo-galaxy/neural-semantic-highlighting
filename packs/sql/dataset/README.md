# SQL corpus

Bounded original-byte source captures use fixed official revisions: PostgreSQL 18
stable tutorials, MySQL 8.4 sys-schema functions/procedures, and Oracle sample
schema scripts. `upstreams.json` pins individual paths and Git blob identities;
full original licenses and SHA-256 capture locks stay with the external sources.
No full database repository is cloned, and no client/server is installed or run.

Original common/dialect-specific tasks share source-family assignments across
profiles. MySQL enable/disable siblings and version helpers are grouped; complete
Oracle schema directories stay together. Exact/lexical/normalized-copy checks
run before windows. Profiles count coverage, not independent projects. Golden
and Playground are excluded. Preserve all old snapshots and full checkpoints.
