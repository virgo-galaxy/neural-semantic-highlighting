# C++ dataset

Original bytes, complete upstream licenses, revision/blob locks, quarantines,
Gold and prepared snapshots stay under `~/Datasets/neural-semantic-highlighting/cpp`.
Bounded captures pin fmt 11.1.4, Catch2 3.8.1, spdlog 1.15.2 and LevelDB 1.23.
The collector never builds or runs collected projects and does not follow includes.

`make dataset-cpp-tools` builds fixed Tree-sitter 0.25.10 / C++ grammar 0.23.4 into
ignored project cache with the existing compiler. No compiler, SDK or global
package is installed. `make dataset-cpp` collects, labels, validates and prepares.
Original focused tasks retain complete source families, not split windows.
Golden and Playground are excluded from collection roots. Missing syntax,
unsupported parser forms, uncovered bytes and invalid coordinates are quarantined.

Exact, lexical and normalized copies are audited before grouped allocation.
Related module headers/implementation files share a family. Freeze the first
`split-groups.json` before training and preserve assignments for later revisions.
Keep natural, focus and visible development evidence separate. Full training
checkpoints remain in `artifacts/cpp`; selected exports cannot resume training.
