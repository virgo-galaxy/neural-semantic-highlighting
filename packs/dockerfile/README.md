# Dockerfile pack

One standalone neural model for Dockerfile/Containerfile source: instructions,
parser directives, multistage names, ARG/ENV/LABEL, flags, paths/references,
Shell/JSON forms, continuations and heredocs. The browser requires no Docker,
Go, Python or source parser. Explicit aliases share one model; no source guessing.

See [semantics](SEMANTICS.md), [dataset](dataset/README.md),
[Golden](fixtures/README.md), [training](../../training/dockerfile/README.md)
and the root [consumer guide](../../README.md).
