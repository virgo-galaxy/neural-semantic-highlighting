42 independently hand-marked original cases define original UTF-16 roles and
modifiers. They cover directive position, case, stages, bindings, quotes/hashes,
flags, JSON, shell commands, continuations/comments, ONBUILD, health checks,
RUN/COPY heredocs, quoted/tab-stripping delimiters, BOM, CRLF and Unicode.
Expected spans are authored directly, never generated by the offline teacher.

Twelve teacher tests include these cases plus multiple heredocs, empty/comment
continuations, custom-shell opacity/reset, shebang opacity, wrong-kind rejection,
invalid input, original-byte coverage and proof that source is not executed.
Golden and eight Playground displays remain outside collection roots. Neural
Golden agreement is a visible edge diagnostic, separate from real held-out data.
