# Svelte pack

`.svelte` template recognition with existing JS/TS and CSS/SCSS/Less model
composition. Targets legacy component syntax and Svelte 5 runes/snippets.

See [semantic contract](SEMANTICS.md), [dataset](dataset/README.md),
[independent Golden](fixtures/README.md) and [training](../../training/svelte/README.md).
No Svelte application runtime, SDK or preprocessor is required for inference.

[Selected model](model/README.md), [evaluation](model/BENCHMARKS.md) and
[known issues](model/KNOWN_ISSUES.md) separate base and composed evidence.
