# Vue Golden fixtures

Independently authored original source with explicit role markers and coverage
profiles for Vue 2, Vue 3 and Vue 3.2. These are visible development expectations,
not training source or an independent corpus accuracy estimate. They cover legacy
filters/slots/directives, modern models/slots/fragments, typed script setup,
language routing, opaque blocks, original entities, Unicode and CRLF.

Gold and neural probes read the same frozen expectations; neither the collector
nor curriculum generator may read these files or Playground demonstrations.
