# PHP dataset

Original source bytes, complete licenses, revision/blob locks, Gold, quarantines
and prepared snapshots stay external under `~/Datasets/neural-semantic-highlighting/php`.
Bounded captures pin Symfony HttpFoundation 7.2.6, Laravel 12.8.1, Monolog 3.9.0
and Guzzle 7.9.3. No PHP project, autoloader, include or Composer dependency runs.

`make dataset-php-tools` builds fixed official Tree-sitter 0.25.10 / PHP 0.24.1
parser sources into ignored cache using the existing compiler. Both tagged PHP
and tagless snippets are parsed offline. No PHP interpreter/SDK/Composer/global
package is installed. `make dataset-php` collects, labels, validates and prepares.

Original syntax/template variants remain in complete task families. Exact,
lexical and normalized copies are audited before family splits and windowing.
Freeze `split-groups.json` before training and retain every earlier assignment
across revisions, including temporarily excluded families. Golden and Playground
are not collection roots. Syntax/coverage/coordinate errors are quarantined.

Natural/focus/base/composed/visible evidence remain separate. Full optimizer/RNG
checkpoints stay in `artifacts/php`. Selected `.pt` and browser exports are not
resumable checkpoints. Preserve all other language data, models and experiments.
