# Perl corpus

A bounded, original-byte capture of host Perl 5.34 core modules and their complete
Perl Artistic/GPL license documents supplies natural source. Files are copied,
not imported or compiled. Source/tool hashes freeze the actual local revision.
Original short/mixed programs add focused grammar; related variants share one
family before windowing. Golden and Playground are never sources.

PPI 1.270 is already present on this host. Its parser runs in an isolated
read-only JSON worker for offline labels; inference uses only PyTorch. Original
CRLF/Unicode coordinates survive the parser's LF view. Preserve all snapshots,
source/license bytes and full checkpoints; never resume the selected export.

A bounded 640-fragment revision retains the existing task-family assignments.
Indented Here Documents cross spaces/tabs, variable/code-like body openings and
source prefixes independently;
short POD, function and quote forms vary their starting positions. No Golden or
Playground text is collected, and no existing source revision is overwritten.

# Quality follow-up

`make dataset-perl-sources` also captures a bounded additional set from the existing
host Perl 5.34 core. `capture_quality.py` fixes namespace folds from path metadata
before reading source. Original namespace assignments, source bytes and licenses
stay intact; the preceding configuration is retained under `history/`.
`quality-protocol.json` separates new natural family holdouts from the exposed
original regression set. No Perl SDK or module dependency is installed, and no
collected module is executed.
