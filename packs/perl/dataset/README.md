# Perl corpus

A bounded, original-byte capture of host Perl 5.34 core modules and their complete
Perl Artistic/GPL license documents supplies natural source. Files are copied,
not imported or compiled. Source/tool hashes freeze the actual local revision.
Original short/mixed programs add focused grammar; related variants share one
family before windowing. Golden and Playground are never sources.

PPI 1.270 is already present on this host. Its parser runs in an isolated
read-only JSON worker for offline labels; inference uses only PyTorch. Original
CRLF/Unicode coordinates survive the parser's LF view. Preserve all snapshots,
source/license bytes and full checkpoints; never resume the selected export.
