# Independent Markdown Golden

48 hand-marked cases cover headings, prose, nested strong/emphasis/deletion,
links/images/references, autolinks, escapes/entities, rules, lists/tasks, tables,
inline/indented/fenced code, metadata, unclosed/unknown fences, opaque HTML/front
matter and exact original BOM/CRLF/Unicode offsets. Fourteen focused checks also
cover container-code scope, no code-language guessing, copy-shape normalization
and fail-closed source/kind guards. Golden never enters training. Teacher
agreement, strict neural agreement, visible examples and untouched natural F1
remain separate evidence sets.
