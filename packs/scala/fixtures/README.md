# Scala independent Golden

33 separately hand-marked cases cover classes/constructor properties, methods,
generics, enums, lambdas, named arguments, extensions, givens/using, imports,
annotations, tuple/case bindings, plain/triple/interpolated strings, nested comments,
backticks, Scala 3 end markers and original Unicode/CRLF. Expectations are independent of teacher output.
Golden and displays never enter training capture. Teacher and neural agreement are
reported separately and never replace natural held-out evaluation.
