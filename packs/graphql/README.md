# GraphQL pack

One standalone model for executable queries/mutations/subscriptions and GraphQL
SDL, including variables, aliases, fragments, directives, input values, type
references, descriptions and comments. `.graphql` and `.gql` share the model.
Browser inference needs no Python, GraphQL server, schema or source parser.

See [semantics](SEMANTICS.md), [dataset](dataset/README.md),
[Golden](fixtures/README.md), [training](../../training/graphql/README.md)
and the root [consumer guide](../../README.md).
