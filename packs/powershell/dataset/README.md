# PowerShell corpus

The bounded capture pins 38 small official PowerShell 7.6 source scripts/modules
and data files, with exact Git blobs and the complete original MIT license.
Source directories remain together. No scripts or modules are imported/executed.

Original tasks cover common functions, command parameters, pipelines, types,
collections, modern operators, quotes, comments and both Here-String forms.
Indentation, prefixes and CRLF vary within the same task family. Golden and
Playground remain outside collection. Immutable external snapshots preserve all
source/Gold/prepared revisions, with source locks and offline tool provenance.
