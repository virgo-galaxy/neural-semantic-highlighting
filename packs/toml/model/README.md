# TOML neural model

TOML .toml configuration, common 1.0 forms and tested 1.1 additions, tables/array tables, dotted/quoted keys, arrays/inline tables, four string and date/time forms.

```ts
const { html } = await highlighter.highlight(source, { language: "toml" });
```

TOML uses one descriptor and canonical toml output. Generic .lock/.conf files are not automatically assigned TOML.
Selective import: `@nsh/highlighter/languages/toml`. Case-normalized IDs share one
model. Browser/Playground consumers require no language SDK, interpreter/compiler,
parser, dependency environment or Python process. Offline Gold uses Pinned toml-eslint-parser 1.0.3 and eslint-visitor-keys 5.0.1 official npm assets, with original licenses and archive/per-file hashes, using existing Node only.
Collected configurations are never executed or built.

[Evaluation](BENCHMARKS.md) separates natural, focus and visible evidence;
[known limits](KNOWN_ISSUES.md) retain measured errors and source-local scope.
Selected .pt/ONNX are inference-only. Resume full artifacts/toml checkpoints only.
All previous data, experiments and formal models remain preserved.
