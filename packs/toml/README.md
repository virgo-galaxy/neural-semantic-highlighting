# TOML pack

TOML configuration highlighting for Cargo, Python/project and application settings.
Common 1.0 forms and explicitly tested 1.1 additions share one model; no SDK,
configuration execution or project dependency installation is required.

See [semantics](SEMANTICS.md), [dataset](dataset/README.md),
[Golden](fixtures/README.md), [training](../../training/toml/README.md)
and [consumer integration](../../README.md).
