# TOML dataset

Original Git commit/tree/blob captures, licenses, immutable corpus/Gold/prepared
revisions stay under `~/Datasets/neural-semantic-highlighting/toml`. Path-hash
bounded selection excludes test/fixture/vendor/generated roots and validates
with the fixed teacher before selection; inventory retains candidate rejections.
Original curriculum configuration families are separate from hand-marked Golden,
focused teacher regressions and Playground probes. Exact/lexical/structural copy
audits run before windowing; source family assignments freeze before training.

Use `make dataset-toml-tools`, `make dataset-toml-sources`, then
`make dataset-toml`. Existing Node runs pinned offline parser/dependency assets
from ignored project cache with retained licenses/hashes. No SDK/global install,
configuration command, project build or dependency execution is involved.
Full optimizer/RNG continuation checkpoints belong under `artifacts/toml`.
